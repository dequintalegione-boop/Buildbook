Дата обновления: 2026-11-26.

## Статус по этапам

| Этап | Статус | Примечание |
|---|---|---|
| 1. Аудит | Выполнен | Зафиксированы архитектура, уже вошедшие PR и gaps; см. аудит |
| 2. Структура вкладки | Частично | Панель, сообщения, диагностика, белый список и журнал есть; требуется довести latency/stale и все состояния |
| 3. Управление локальным компонентом | Частично | Start/stop/restart и защита от повторных экземпляров есть; требуется Windows smoke-test |
| 4. Установка и мастер | Частично | Мастер токена и проверка Bot API есть; выбор папки данных есть в скрипте, но выбор и сохранение папки установки приложения не реализованы |
| 5. Белый список | Реализация в PR #25 | Active/disabled, addedAt, синхронизация активных ID с gate, обратная совместимость v1 |
| 6. Команды и финансы | Частично | Доход, расход и статистика работают через канонический профиль; отдельные переключатели исполнения команд ещё не реализованы |
| 7. Журнал и диагностика | Реализация в PR #25 | Неограниченное хранение по умолчанию, offset pagination, поиск/фильтр, экспорт полной истории |
| 8. Автозапуск и восстановление | Частично | Scheduled Task и диагностика есть; аварийное восстановление требуется подтвердить на Windows |
| 9. Тестирование | В работе | Добавлены регрессионные тесты; нужны CI и проверка установленного PWA на Windows |

## Следующие обязательные задачи

1. Реализовать серверные настройки включения/выключения каждой поддерживаемой команды.
2. Добавить реальную проверку Telegram API с измерением задержки и stale-индикатором.
3. Завершить установочный сценарий с единственным выбором папки установки приложения и сохранением пути.
4. Проверить Windows Task Scheduler: аварийно завершить host, дождаться повтора, подтвердить восстановление polling без второго экземпляра.
5. Пройти полный чек-лист раздела 9 исходного плана на установленном PWA.
