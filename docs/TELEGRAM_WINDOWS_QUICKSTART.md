# Быстрый запуск Telegram на Windows

Этот сценарий подходит для локальной копии Buildbook. Telegram polling остаётся выключенным, пока вы отдельно не завершите перенос профиля и не включите его вручную.

## Перед началом

- Установите Node.js 22 LTS или новее.
- Скачайте/клонируйте весь репозиторий, а не только BAT-файл.
- Не запускайте скрипты из непроверенной папки. BAT-файлы вызывают PowerShell с обходом ExecutionPolicy только для указанного скрипта.
- Не отправляйте токен бота, `.env` или ключ локального API кому-либо.

## Настройка

1. Откройте папку проекта в проводнике и перейдите в `scripts`.
2. Запустите `setup-buildbook-telegram.bat`. Мастер запросит папку данных (можно оставить предложенную), числовой Telegram user ID и токен бота. Токен вводится скрыто.
3. Мастер создаст или обновит корневой `.env`, сгенерирует ключ API и сохранит копию прежнего `.env`, если он был. Проверьте, что файл не попал в синхронизируемую/публичную папку.
4. Запустите `start-buildbook-local-host.bat` из той же папки `scripts`. Оставьте окно открытым. Если запуск завершился ошибкой, изучите сообщение в окне и `data/local-host.log`.
5. Откройте `http://127.0.0.1:43127/` в браузере и перейдите во вкладку Telegram. Не переключайтесь между адресами `127.0.0.1` и `localhost`: браузер считает их разными origin.
6. Подключите локальный хост ключом API из `.env`. Ключ нужен для первоначального обмена на сессию; токен Telegram-бота в браузер не вводится.

## Важно перед включением бота

Мастер намеренно оставляет `BUILDBOOK_TELEGRAM_ENABLED=false`. Сначала создайте резервную копию IndexedDB, перенесите профиль в файловое хранилище хоста, проверьте чтение обратно и контрольную сумму, затем явно переключите интерфейс на канонический профиль. После перезапуска убедитесь, что вкладка Telegram показывает активное каноническое хранилище.

Только после этих проверок остановите хост, измените `BUILDBOOK_TELEGRAM_ENABLED=false` на `true` в локальном `.env` и запустите хост снова. Не включайте polling, если интерфейс и Telegram могут работать с разными профилями: это создаёт два независимых финансовых журнала.

Чтобы остановить хост, нажмите `Ctrl+C` в окне BAT. Окно не закрывайте, пока приложение и Telegram должны работать.

## Ограничения мастера

- Мастер настраивает локальный `.env`, но не устанавливает системную службу и не включает автозапуск.
- Токен хранится в `.env`; это не хранилище секретов Windows.
- Если автоматическое ограничение ACL не удалось, мастер предупредит об этом. Проверьте права доступа к `.env` вручную.
- Браузер не может запускать локальные BAT/PowerShell-файлы напрямую. Скрипты запускаются пользователем из доверенной папки проекта.
